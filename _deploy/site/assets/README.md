# /assets — obrázky a média

Sem patří fotky kuchyní, loga a obrázky pro OG (sdílení na sítích).

## Struktura

```
assets/
├─ og-default.jpg          # 1200×630 — defaultní OG obrázek pro stránky bez vlastního
├─ hero.jpg                # 2400×1350 — hero homepage
├─ gallery/
│  ├─ lara.jpg             # ~1600×1200 — fotky modelů do galerie a homepage
│  ├─ lana.jpg
│  ├─ fiora.jpg
│  └─ ...                  # všechny modely z galerie.html
├─ atelier/
│  ├─ exterior.jpg
│  ├─ interior-01.jpg
│  └─ ...
└─ partners/
   ├─ sachsenkuechen.svg
   ├─ akp.svg
   ├─ teka.svg
   └─ kuppersbusch.svg
```

## Formát

- Hero a galerie: **JPG**, Q 80–85, ≤300 kB
- Loga partnerů: **SVG** (vektor, ne JPG)
- OG: **JPG**, 1200×630, ≤200 kB

## Atribuce

Fotky z press kitu SACHSENKÜCHEN GmbH (jako výhradní zastoupení mám oprávnění k použití).
Pro vlastní realizace v atelieru: focení doplníme postupně, atribuce bude `© dhouse atelier`.
